# [!DNL Coworker] Memory: personalizing AI for more productive workflows

[!DNL Coworker] Memory helps create more consistent, efficient, and personalized interactions by remembering the preferences, corrections, and working styles that matter most to your work.

Instead of repeating the same instructions every time you start a new conversation, Memory allows Coworker to carry forward selected information across sessions, helping deliver faster and more relevant responses.

>[!VIDEO](https://video.tv.adobe.com/v/3503657/?learn=on&enablevpops)

## Understanding Memory

Memory is designed to retain useful information across conversations, including:

- Preferred response formats
- Working styles and communication preferences
- Business terminology
- Professional context
- Reporting defaults and analytical preferences
- Time zone settings

For example, if you consistently prefer concise bullet-point responses or use specific terminology for business objects, Coworker can remember those preferences and apply them automatically in future conversations.

## Memory vs. Conversation History

Memory and conversation history serve different purposes.

### Conversation History

Conversation history allows you to:

- Return to previous chats
- Review earlier discussions
- Reference past interactions

### Memory

Memory allows Coworker to:

- Retain selected preferences
- Apply saved corrections
- Personalize future interactions
- Improve consistency across sessions

Memory is a personalization layer, not a record of every conversation.

## Memory vs. Business Context

Memory should not be confused with Business Context.

### Business Context

Business Context grounds Coworker in organizational information such as:

- Company data
- Policies
- Governance frameworks
- Connected enterprise systems

### Memory

Memory is focused on the individual user and their preferences.

It helps personalize interactions but does not replace organizational data sources, permissions, or governance controls.

## Storing Preferences in Memory

One of the easiest ways to save information is by clearly stating it during a conversation.

Examples include:

- Professional role and responsibilities
- Preferred communication style
- Reporting preferences
- Time zone information
- Frequently used terminology

Using phrases such as "Remember..." allows Coworker to identify preferences that should be retained for future sessions.

## Practical Example: Campaign Performance Reporting

The video demonstrates how Memory can streamline reporting workflows using Customer Journey Analytics.

In the example:

1. A user requests a campaign performance report.
2. Coworker identifies data sources and reporting components.
3. The user saves preferred reporting settings to Memory.
4. Coworker automatically applies those preferences in future analyses.

As a result, subsequent reports are delivered using the user's preferred dimensions, metrics, and reporting assumptions without requiring additional instructions.

## Managing Memory

Users remain in control of the information stored in Memory.

Within **Customizations > Memory**, users may be able to:

- Enable or disable Memory
- Review stored preferences
- Inspect individual memory entries
- Edit saved information
- Delete memories that are no longer useful

Available controls may vary depending on organizational settings and the Adobe experience enabled by administrators.

## Important Considerations

Memory is designed for personalization, not as a system of record.

Do not rely on Memory as the authoritative source for:

- Customer data
- Campaign performance data
- Legal requirements
- Compliance decisions
- Security decisions

Memory also does not:

- Grant access to Adobe products
- Provide additional permissions
- Override governance controls
- Replace organizational data systems

Always follow your organization's governance policies and administrator guidance.

## Key Takeaways

Adobe Coworker Memory helps reduce repetitive instructions and create more personalized AI experiences by carrying important preferences and corrections across conversations.

By remembering how you like to work, Coworker can become increasingly helpful over time while still operating within the governance and security controls established by your organization.
