# What are skills in Coworker?

Skills are reusable playbooks that help Adobe CX Coworker perform customer experience orchestration tasks consistently and efficiently. Rather than repeatedly explaining the same process, teams can use Skills to standardize common workflows, reporting methods, and analysis approaches across conversations and users.
 
In this video, you'll learn how Skills work, when to use them, and how they help teams scale repeatable customer experience practices.

>[!VIDEO](https://video.tv.adobe.com/v/3502322/?learn=on&enablevpops)

A Skill provides:

- Instructions for completing a specific type of task
- The steps Coworker should follow
- The information and data sources to use
- The expected output format
- Guidance on when the workflow should be applied

## Why Teams Use Skills

Many organizations perform the same types of tasks repeatedly, including:

- Weekly performance reporting
- Customer journey analysis
- Executive summaries
- Standardized business reviews
- Repeatable analytics workflows
 

Skills help teams capture and reuse these best practices without manually re-explaining the process each time.
 
## Skills and Data Governance

Skills do not store customer data.

Instead, Skills define how work should be performed while data access remains governed through connected Adobe applications, permissions, and organizational controls.

This separation allows teams to standardize processes while maintaining proper security and governance.
