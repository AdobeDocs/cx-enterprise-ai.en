# Manage Plugins and Marketplaces

Learn how administrators can extend Adobe Coworker Chat with approved plugins, manage marketplaces, and govern access to skills and connected tools while maintaining alignment with existing Adobe permissions.

>[!VIDEO](https://video.tv.adobe.com/v/3504182/?learn=on&enablevpops)

## What you'll learn
 
In this video, you'll explore how plugin management works in Adobe Coworker and how Administrators can safely introduce new capabilities for their teams.
 
You'll learn:
 
- The difference between marketplaces, plugins, skills, and MCP servers
- How plugins package skills and connected services for use in Coworker
- Why Adobe product permissions and product profiles determine access to capabilities
- How Coworker automatically inherits permissions from connected Adobe products
- Why validating your Experience Cloud organization and Experience Platform sandbox is an important administrative step
- How to navigate the Customizations area of Coworker
- How to add a new marketplace using a GitHub repository
- How to install and manage plugins for your organization
- How to review the skills included in a plugin before deployment
- How to determine whether users can install or remove plugins themselves
- What to consider before removing a plugin from your environment
- How users can customize their own workspace within administrator-defined boundaries
