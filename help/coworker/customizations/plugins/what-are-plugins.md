# Coworker Plugins: what they are, how they work, and how to install them

This video introduces plugins and explains how they extend [!DNL Coworker] with new capabilities. You will learn what a plugin is, what components it contains, how plugins relate to skills and MCP servers, and how to install, use, and remove plugins from your workspace.

>[!VIDEO](https://video.tv.adobe.com/v/3503656/?learn=on&enablevpops)

## What Is a Plugin?

A plugin is an installable package of related capabilities for Adobe Coworker. Think of it as a ready-to-use toolkit designed for a specific business function or use case.

A plugin can include:

- Specialized skills that perform specific tasks
- MCP servers that connect Coworker to external Adobe solutions and services
- Bundled functionality that simplifies deployment and management

## Understanding Key Concepts

The video explains the relationship between several important components:

| Component | Purpose |
|-----------|---------|
| Marketplace | Catalog where available plugins are discovered |
| Plugin | Installable package of capabilities |
| Skills | Reusable instructions that perform specific tasks |
| MCP Servers | Governed connections to external tools and services |

Examples of connected Adobe solutions include:

- Adobe Journey Optimizer
- Real-Time CDP
- Adobe Target
- Adobe Workfront

## Using a Plugin in Coworker

After installation, the video shows how a plugin can be used in a chat experience.

The example demonstrates creating a loyalty challenge that awards points to rewards members after making a purchase.

During execution, Coworker provides transparency into:

- The skills being used
- The data sources consulted
- Queries that were executed
- How results were generated

## Governance and Security

A key takeaway is that installing a plugin does not bypass organizational governance controls.

Coworker continues to honor:

- User permissions
- Access controls
- Approval requirements
- Adobe organization governance policies

Installing a plugin does not automatically grant access to products or actions that a user is not already authorized to use.

## Removing Plugins

The video concludes by demonstrating how to remove an installed plugin when it is no longer needed.

Removing a plugin also removes the capabilities bundled within that package.

## Key Takeaway

Plugins make Coworker extensible by packaging related skills and governed connections into installable solutions. Marketplaces help users discover plugins, skills perform specific tasks, and MCP servers connect Coworker to Adobe Experience Cloud applications and services in a secure, governed way.
